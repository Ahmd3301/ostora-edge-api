الفكرة الأساسية مفهوم النظام وتصنيفاته البيئية

النظام هو مجموعة من الموارد والعناصر المترابطة التي تتفاعل داخل إطار معين لتحقيق هدف مشترك.

شرح مبسط: تخيل ساعة يد ميكانيكية؛ تروس وعقارب وبطارية مختلفة تتكامل معاً، إذا تعطل ترص واحد يتأثر نظام إخراج الوقت بالكامل.

شرح أكاديمي: النظم تصنف هيكلياً وبيئياً كالتالي:

  • النظام الطبيعي: من صنع الخالق ولا دخل للبشر فيه (مثل الكون، الشمس، الأمطار).
  • النظام الاصطناعي: من تصميم وبناء البشر لخدمة أغراضهم (مثل المنشآت الاقتصادية، الحواسب).
  • النظام المفتوح (Open System): يتأثر ويؤثر في البيئة الخارجية المحيطة، وتعتمد المنظمات عليه لتبادل مدخلاتها ومخرجاتها.
  • النظام المغلق (Closed System): معزول كلياً عن محيطه الخارجي ولا يتأثر به (تطبيقياً نادر جداً في العلوم الاجتماعية والإدارية).
  • النظام الاحتمالي (Probabilistic System): نظام لا يمكن التنبؤ بحالته المستقبلية بيقين، ونحتاج لدراسته إلى استخدام الطرق الإحصائية والاحتمالية (مثل حركة السوق المالي).
خدعة متكررة يدمج واضع الامتحان في صياغة العبارات بين مفهوم النظام الطبيعي والنظام المفتوح أو الاحتمالي للتشويش المباشر على الطالب.

الفكرة الأساسية هرمية البيانات ووحدات القياس بالحاسب

البيانات هي المادة الخام والمشاهدات الأولية، بينما المعلومات هي المادة المعالجة والمنظمة الصالحة فوراً لاتخاذ القرار.

الوحدة التفاصيل التقنية والمعادلة الأهمية للامتحان
البايت (Byte) يحتوي على 8 بت (Bits) فقط. فخ متكرر: يدعي في السؤال أنها تحتوي على 16 بت.
الكيلوبايت (KB) 1024 بايت. الوحدة الأساسية للملفات النصية البسيطة.
الميجابايت (MB) 1024 كيلوبايت. أكبر بكثير من البايت الفردي.
التيرابايت (TB) 1024 جيجابايت. أكبر بكثير من الميجابايت وهي وحدات السعة الضخمة.

الفكرة الأساسية هيكل نظم المعلومات بالمنظمات

تتوزع النظم بالمنظمة بحسب الهرم الإداري التقليدي كالتالي:

  • المستوى التشغيلي (الأدنى): يخدمه نظم معالجة المعاملات TPS، ويهتم بالعمليات اليومية الروتينية (البيع، الشراء، حركات الصراف الآلي ATM).
  • المستوى التكتيكي/المعرفي (الأوسط): تخدمه نظم المعلومات الإدارية MIS ونظم إدارة المعرفة KMS وميكنة المكاتب OAS. تركز على إنتاج التقارير الدورية والتقارير الاستثنائية.
  • المستوى الاستراتيجي (الأعلى): تخدمه نظم دعم القرار DSS ونظم دعم الإدارة العليا ESS، وتركز على القرارات شبه الهيكلية أو غير الروتينية الطويلة المدى.

لماذا هذا مهم؟ لا يمكن لنظم الـ TPS دعم الإدارة العليا بقراراتها الاستراتيجية، فمهمتها مقتصرة تماماً على المعاملات والعمليات اليومية.

الفكرة الأساسية الأنظمة المتكاملة والبيانات الضخمة

  • نظام تخطيط موارد المؤسسة (ERP): نظام موحد مدمج يربط الأقسام والعمليات المختلفة (المالية، الموارد البشرية HR، المشتريات والمخازن MM، البيع) في قاعدة بيانات مركزية مشتركة.
  • نظام إدارة علاقات العملاء (CRM): يهدف لبناء علاقات طويلة الأمد مع العملاء من خلال تتبع وتحليل معلوماتهم، ومؤشر CLTV يقيس قيمة عمر العميل للشركة استناداً لإيراداته المستقبلية المتوقعة.
  • مستودعات البيانات (Data Warehouse): قاعدة بيانات تاريخية ضخمة تجميعية تساند الإدارة في تحليل البيانات واتخاذ القرارات الإدارية، وتعتمد على تقنيات التنقيب عن البيانات Data Mining لإيجاد علاقات منطقية مخفية ومفيدة.

الفكرة الأساسية وحدات الإدخال والإخراج وذاكرة الحاسب

التمييز الدقيق بين المكونات المادية يمنع خسارة الدرجات في الأسئلة السريعة:

  • وحدات الإدخال: ماسح الباركود، قارئ الـ QR Code، قارئ العلامات البصرية OMR، الميكروفون، والماسح الضوئي (Scanner).
  • وحدات الإخراج: الشاشة التقليدية، السماعات، كارت الشاشة VGA، وطابعات الليزر (وهي الأسرع مقارنة بطابعات Inkjet القديمة).
  • شاشة اللمس (Touch screen): وحدة إدخال وإخراج مشتركة في نفس الوقت.
  • RAM مقابل ROM: الـ RAM ذاكرة عشوائية للقراءة والكتابة وتفقد محتوياتها بانقطاع الكهرباء، بينما الـ ROM ذاكرة قراءة فقط دائمة تحفظ تعليمات الإقلاع الأساسية للنظام.

الفكرة الأساسية المترجم (Compiler) والمفسر (Interpreter)

المترجم يحلل البرنامج بالكامل دفعة واحدة ويحوله للغة الآلة، بينما المفسر يقوم بالترجمة والتنفيذ سطراً بسطر أو فقرة فقرة.

الفكرة الأساسية أنواع البيانات وتكوين الجمل

لكتابة وإعداد الجمل البرمجية الصحيحة للامتحان:

  • المتغيرات العددية الصحيحة نستخدم معها int أو Integer (مثل: score = 90).
  • المتغيرات العشرية والكسرية نستخدم معها float أو double (مثل: Price = 20.95).
  • المتغيرات النصية نستخدم معها الكلمة المحجوزة String (مثل: "Celia").
  • المتغيرات المنطقية نستخدم معها boolean وقيمها تكون فقط true أو false.
  • الإعلان عن الثوابت التي لا تتغير قيمتها أثناء التشغيل يتم باستخدام الكلمة المفتاحية final.
  • عامل عدم التساوي البرمجي في جافا يكتب كالتالي: !=.
  • باقي القسمة يتم عبر الرمز % (مثال: 5 % 2 = 1، بينما 4 % 2 = 0).

الفكرة الأساسية الدوال المحاسبية والإحصائية والتركيبية

الخلايا هي نقطة تقاطع الأعمدة (التي تأخذ حروفاً مثل A, B, C) مع الصفوف (التي تأخذ أرقاماً مثل 1, 2, 3).

  • دالة COUNT(): تحسب الخلايا التي تحتوي على قيم رقمية فقط وتتجاهل النصوص تماماً.
  • دالة COUNTA(): تحسب جميع الخلايا غير الفارغة بغض النظر عما إذا كانت أرقاماً أو نصوصاً (مثل رصد حضور وغياب الطلاب).
  • دالة SUMIF(): دالة الجمع الشرطي، تُستخدم لفصل وجمع القيم المدينة عن الدائنة في الدفاتر المالية.
  • الأمر Merge Cells: يستخدم لدمج خلايا متعددة لتبدو كخلية واحدة وليس لترتيب أو فرز البيانات (فرز البيانات هو وظيفة Sort).

💡 حيلة الحفظ السريع 1: التفريق بين الرموز الأمنية الكبرى

لضمان عدم التداخل بين طرق الاختراق والتهديدات الأمنية بالمنظمات:

  • الاصطياد (Phishing): تذكر كلمة Fish (صيد) 🎣؛ المخترق يلقي لك طعماً (رسالة بريد إلكتروني كاذبة أو رسالة نصية مزيفة) وينتظر أن تبتلعه لسرقة بياناتك.
  • التوجيه الكاذب (Pharming): تذكر كلمة Farm (مزرعة) 🚜؛ المخترق لا يرسل رسائل، بل يقوم "بزرع" نظام لإعادة توجيهك تلقائياً لنسخة مزيفة بالكامل من الموقع الأصلي لتدخل بياناتك بنفسك دون وعي.

💡 حيلة الحفظ السريع 2: لغات البرمجة ودوال إكسيل

  • COUNT: حرف (N) يرمز للرقم Numbers 🔢 (تعد الأرقام فقط).
  • COUNTA: حرف (A) يرمز لـ All (الجميع) 🔠 (تعد الأرقام والنصوص وكل خلية غير فارغة).
  • Compiler (المترجم): يبدأ بـ (C) كأنه يترجم Complete (كامل) البرنامج مرة واحدة 📦.
  • Interpreter (المفسر): يترجم الكود سطراً بسطر (Line by Line) 📝.

🔥 أولاً: فك وحل المعادلات الإكسيل المركبة والمنطقية

المسألة: احسب ناتج المعادلة التالية بفرض أن الخلايا تحتوي على: A1=10, A2=20, A3=30, A4=40

=A1/2 * IF(SUM(A1:A4)>=100, 20, 0)

الحل الرياضي والمنطقي خطوة بخطوة:

  1. أولاً، نقوم بحساب العمليات داخل دالة الجمع: SUM(A1:A4) = 10 + 20 + 30 + 40 = 100.
  2. نقوم بتقييم الشرط المنطقي داخل دالة IF: هل المجموع (100) أكبر من أو يساوي 100؟ نعم، الشرط صحيح تماماً (True).
  3. بما أن الشرط صحيح، يرجع الإكسيل القيمة الأولى للشرط وهي 20.
  4. نقوم بحل العملية الحسابية الخارجية: A1 / 2 = 10 / 2 = 5.
  5. نضرب النتيجة الخارجية بقيمة دالة الـ IF: 5 * 20 = 100.

الناتج النهائي الصحيح هو: 100

💻 ثانياً: برمجيات الجافا الإحصائية والحسابية

المسألة: صمم برنامج جافا متكامل لقراءة درجات الطلاب وحساب المتوسط، النهاية العظمى، والنهاية الصغرى.

import java.util.Scanner;

public class StudentGrades {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("أدخل عدد الطلاب: ");
        int n = input.nextInt();
        double[] grades = new double[n];
        double sum = 0;
        
        for(int i = 0; i < n; i++) {
            System.out.print("أدخل درجة الطالب رقم " + (i+1) + ": ");
            grades[i] = input.nextDouble();
            sum += grades[i];
        }
        
        double maxScore = grades[0];
        double minScore = grades[0];
        
        for(int i = 1; i < n; i++) {
            if(grades[i] > maxScore) maxScore = grades[i];
            if(grades[i] < minScore) minScore = grades[i];
        }
        
        double averageScore = sum / n;
        
        System.out.println("المتوسط الحسابي للدرجات: " + averageScore);
        System.out.println("النهاية العظمى للدرجات: " + maxScore);
        System.out.println("النهاية الصغرى للدرجات: " + minScore);
    }
}
